# 1대1 본소 간편 배분 — 2026-11-17

입력폼 검토의 첫 우선순위인 일반 사건 배분 입력을 단순화했다. 기존 계산기와 v2 저장 형식을 그대로 사용하며 별도 계산 공식을 추가하지 않는다.

## 사용 흐름

1. 사건·당사자와 본소, 심급, 비용 부담 주문의 정방향·역방향 비율을 입력한다.
2. 대리인·비용 목차에서 각 비용의 발생 절차, 지출·귀속 당사자 한 명, 관련 청구, 금액·증빙을 입력한다. 자동 보수는 심급별 소가·실비를 입력한다.
3. 배분·검토 목차에서 절사·상계 설정을 확인하고 비용을 펼친다. ‘1대1 본소 간편 배분’에 앞서 입력한 귀속자·상대방·청구가 표시된다.
4. 해당 비용의 부담 관계를 확인하고 **간편 배분 계획 적용**을 누른다. 후보가 한 건이면 미리 선택해 보여 주며, 여러 후보는 사용자가 선택해야 한다. 선택한 주문 원문과 이 비용에 적용할 상대방의 비율을 함께 표시한다.
5. 확정신청비용에 다른 절차의 주문을 적용할 때는 준용 근거를 입력해야 적용할 수 있다. 확정신청 자체의 부담 주문이 적용되면 별도 준용 근거는 선택 사항이다.
6. 계산 결과와 근거를 검토한 후 브라우저에 초안을 저장하고 계산서를 생성한다.

선택·준용 근거는 적용 전에는 임시 화면 상태다. 접기·펼치기는 이를 유지하지만 저장 초안 복원·사례 교체·새 초안은 임시 선택을 초기화한다. 적용 후에는 실제 초안과 계산에 반영되고 기존 계산서 미리보기는 무효화된다. 확정되지 않은 임시 선택으로 기존 계산 결과를 바꾸지 않는다.

## 지원 범위와 보존 규칙

- 신청인 1명·피신청인 1명, 본소 1건, 각 심급에 두 당사자가 참여하고 비용 귀속자가 한 명인 경우.
- 제1심·항소심·상고심 및 확정신청. 본안 비용의 관련 청구는 해당 본소여야 한다.
- 부담 주문 후보는 당사자 쌍, 적용 절차·청구, 원문, 양방향 비율의 형식을 확인해 좁힌다. 주문 효력이 미확인인 경우 표시하고 기존 계산기의 검토 경고를 유지한다. 법률적 적용 여부를 자동 확정하지 않는다.
- 적용 시 비용 전액을 귀속자에게 귀속하는 말단 계획을 만들고 배분 대상 두 명·직접 귀속 분류를 함께 설정한다. 부담 비율은 비용 부담 주문에서 가져온다. 1대1의 상대방과 청구를 반복 선택할 필요가 없다.
- 기존 계획이 말단 하나이거나, 한 개 분기만 있는 균등 단계들로 말단 하나에 연결된 경우에는 기존 ID·명칭·단계와 수동 산정 기초 그룹을 보존하고 말단 관계만 수정한다. 화면을 열었다는 이유로 저장 내용을 변환하지 않는다.
- 다수 당사자, 반소·복수 청구, 공동 귀속, 환송, 가중치·여러 분기 또는 다른 귀속 범위가 있는 기존 계획은 직접 편집한다. 한 분기뿐인 가중치 단계도 가액 참조·검증 의미가 있으므로 자동으로 없애지 않는다.
- 비용 금액·환급·실비·인정액·증빙·메모 및 절사·법정상계 판단은 자동 변경하지 않는다. 기존 배분 근거는 유지하고 공란일 때만 간편 계획의 설명을 채운다.
- 수동 인정액 방식의 변호사보수는 기존과 같이 산정 기초 그룹 연결이 별도로 필요하다. 간편 입력은 누락한 금액이나 보수 소가, 상대방 자료 제출, 절사·상계 결정을 추정하지 않는다.

일반 사건에 필요한 계산용 계획을 먼저 배치하고, 기존 배분 대상·분류·근거의 직접 편집은 추가 접기 영역으로 옮겼다. 복합 사건용 단계 편집도 계속 제공한다. 전체 펼치기는 모든 세부 편집 영역을 연다.
