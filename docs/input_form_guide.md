최신 기본 사건 흐름은 [1심·본소·1대1 안정화](litigation-costs-basic-stabilization.md)를 따른다. 아래 초기 설계의 상계·분리확정 체크 연동은 실제 검증에서 발견한 문제로 인해 분리했다.

현재 기능의 검증 범위·제약은 [검증 기준과 현황](litigation-costs-validation-plan.md)을 참고한다. 아래는 입력 UX 설계안이며, 항목이 표시된다는 사실만으로 해당 법률 유형의 계산·출력이 검증된 것은 아니다.

실무에서 겪는 가장 복잡한 케이스(공동소송 안분, 본소·반소 병합, 상계, 청구감축, 파기환송 등)까지 모두 수용할 수 있도록 **스텝(Step) 또는 아코디언(Accordion) 방식의 UI 입력 폼 구조**를 설계했습니다.

사용자가 불필요한 입력창에 압도되지 않도록 **조건부 노출(Conditional Rendering)** 규칙도 함께 명시했습니다.

### Step 1. 사건 및 당사자 기본 설정

사건의 뼈대와 인원수, 지위를 확정하여 이후 단계의 입력 필드를 동적으로 생성하는 단계입니다.

* **1-1. 확정사건 기본 정보**
* `텍스트 입력창(Input)` : 소송비용액확정 사건번호 (예: 2026카확35081)
* `라디오 버튼(Radio)` : 확정된 최종 심급 선택 (`1심 확정` / `2심(항소심) 확정` / `3심(상고심) 확정`)
* *동작:* 선택에 따라 Step 2~4의 심급 탭이 자동 생성됨


* `라디오 버튼(Radio)` : 신청인의 본안 지위 (`원고(반소피고)` / `피고(반소원고)` / `승계인`)


* **1-2. 병합 및 특수 절차 여부 (복수 선택 가능)**
* `체크박스(Checkbox)` : 반소(예비적 반소 포함) 병합 사건
* `체크박스(Checkbox)` : 파기환송 사건 포함 *(체크 시 환송 전·후 항소심 변호사보수 1회 통합 로직 적용)*
* `체크박스(Checkbox)` : 피신청인의 상계 의견서 제출 *(체크 시 Step 4에 '피신청인 지출 비용' 입력 탭 활성화)*


* **1-3. 당사자 명단 및 변호사 선임 형태**
* **[동적 테이블] 신청인 측 목록** (`+ 행 추가` 버튼 제공)
* `텍스트 입력창(Input)` : 성명/법인명 (예: 박경임)
* `셀렉트박스(Select)` : 지위 (`원고` / `피고` / `승계인`)
* `셀렉트박스(Select)` : 변호사 선임 그룹 (`공동선임 A그룹` / `개별선임 1` / `개별선임 2`...)


* **[동적 테이블] 피신청인 측 목록** (`+ 행 추가` 버튼 제공)
* `텍스트 입력창(Input)` : 성명/법인명 (예: 이종현)
* `셀렉트박스(Select)` : 지위 (`피고` / `원고` / `보조참가인` 등)
* `체크박스(Checkbox)` : 1심 분리확정 여부 *(체크 시 2·3심 안분 계산에서 자동 제외)*
* `셀렉트박스(Select)` : 변호사 선임 그룹 (`공동선임 B그룹` / `개별선임 1`...)

### Step 2. 심급별 소가(소송목적의 값) 및 안분 기준

Step 1에서 선택된 심급(`1심`, `2심`, `3심`)과 `반소 여부`에 따라 입력 매트릭스가 자동 구성됩니다.

* **2-1. 심급별 소가 설정 (1심 / 2심 / 3심 탭 구분)**
* `체크박스(Checkbox)` : 소송 도중 청구취지 변경(감축·확장) 있음
* *(미체크 시)* `숫자 입력창(Number)` : 본소 소가 (원)
* *(체크 시)* `숫자 입력창(Number)` : 최초 소가(납부 인지대 검증용) / `숫자 입력창(Number)` : 최종 변경 소가(변호사보수·안분 기준용)


* *(Step 1에서 '반소 병합' 체크 시 노출)*
* `숫자 입력창(Number)` : 반소(또는 예비적 반소) 소가 (원)
* `라디오 버튼(Radio)` : 본소와 반소의 목적 동일 여부 (`목적 다름 - 소가 합산` / `목적 동일 - 다액 기준`)


* *(2심 탭 전용)* `숫자 입력창(Number)` : 항소가 / `숫자 입력창(Number)` : 부대항소가 (해당 시)


* **2-2. 공동소송인별 안분 소가 (당사자가 2인 이상일 때만 노출)**
* `라디오 버튼(Radio)` : 당사자 간 소가 배분 방식 (`전원 동일(균등)` / `당사자별 개별 소가 입력`)
* *(개별 소가 선택 시)* **당사자별 소가 매트릭스 테이블**
* 행(Row): Step 1에서 등록한 원고/피고 명단
* 열(Column): `주위적청구 소가` / `예비적청구 소가` / `흡수(중복) 제외 소가` (`숫자 입력창`)
* 하단 자동 합계 표시(Read-only): `전체 소가` 및 `안분 기준 총소가` 자동 계산 출력

### Step 3. 판결 주문의 소송비용 부담 비율

판결문 주문의 문구를 구조화된 비율 데이터로 변환하여 입력받는 단계입니다.

* **3-1. 심급별 부담 비율 설정 (1심 / 2심 / 3심 각각)**
* `셀렉트박스(Select)` : 부담 방식 유형
* `전부 부담` (예: 피고 전부 부담)
* `비율/분수 부담` (예: 원고 1/3, 피고 2/3 또는 40% : 60%)
* `본소·반소 분리 부담` (예: 본소는 원고, 반소는 피고 부담)


* *(비율/분수 선택 시)*
* `토글/라디오` : 입력 단위 (`퍼센트(%)` / `분수(분자/분모)`)
* `숫자 입력창(Number)` : 원고 측 부담 비율 ↔ `자동 계산(Read-only)` : 피고 측 부담 비율 (`100% - 원고비율`)


* *(본소·반소 분리 선택 시)*
* `셀렉트박스(Select)` : 본소 비용 부담자 (`원고` / `피고` / `비율 입력`)
* `셀렉트박스(Select)` : 반소 비용 부담자 (`원고` / `피고` / `비율 입력`)




* **3-2. 공동소송인 간 부담 특약**
* `라디오 버튼(Radio)` : 공동소송인 부담 형태 (`각자 부담(분할/안분)` / `연대(합동) 부담`)



---

### Step 4. 심급별 본안 지출 비용 입력

상계 여부에 따라 `[신청인 지출 비용]` 탭과 `[피신청인 지출 비용]` 탭으로 나뉘며, 각 탭 내부는 심급별 아코디언으로 구성됩니다.

* **4-1. 변호사보수 (심급별)**
* `숫자 입력창(Number)` : 착수금 실제 지급액
* `숫자 입력창(Number)` : 기지급 성공보수액
* `숫자 입력창(Number)` : 지급 예정 성공보수 약정액 (위임계약서 기준)
* `체크박스(Checkbox)` : 소명자료(세금계산서·영수증·계약서) 첨부 확인
* `자동 계산 배지(Read-only)` : **보수규칙 제3조 상한액** vs **실제 지급·약정 합계액** 비교 후 **최종 산입 인정액** 실시간 표시


* **4-2. 인지대 (심급별)**
* `체크박스(Checkbox)` : 전자소송 접수 (10% 할인 자동 적용, 기본값 Checked)
* `숫자 입력창(Number)` : 실제 납부한 인지액 (원)
* `자동 계산 배지(Read-only)` : 최종 소가 기준 법정 인지액과 비교 후 **최종 산입 인정액** 표시


* **4-3. 송달료 (심급별)**
* `라디오 버튼(Radio)` : 입력 방식 (`납부액·환급액 분리 입력` / `실지출액 직접 입력`)
* `숫자 입력창(Number)` : 최초 납부 송달료 / `숫자 입력창(Number)` : 환급 송달료 → `실지출액 자동 산출`


* **4-4. 기타 법원 절차 비용 (감정료, 증인여비 등)**
* `+ 비용 항목 추가` 버튼으로 동적 행 생성
* `셀렉트박스(Select)` : 비목 선택 (`감정료(측량·시가·감정 등)` / `증인여비` / `당사자 기일출석비용` / `검증비용` / `기타 법원보관금 지출`)
* *(안내 툴팁: 사설 녹취록, 포렌식, 번역료 등은 산입 불가 항목임을 안내)*


* `텍스트 입력창(Input)` : 세부 메모 (예: 1차 측량감정료)
* `숫자 입력창(Number)` : 납부액 / `숫자 입력창(Number)` : 환급액



---

### Step 5. 소송비용액 확정신청 비용 (신청인 측)

본안 이후 확정결정 신청 단계에서 발생한 비용을 입력합니다.

* **5-1. 신청 인지대 및 송달료**
* `숫자 입력창(Number)` : 신청 인지대 (기본값 `900`원 자동 세팅, 수정 가능)
* `숫자 입력창(Number)` : 기발생 송달료
* `숫자 입력창(Number)` : 결정정본 송달료 (기본값 `5,640`원 등 세팅 가능)
* `숫자 입력창(Number)` : 모바일단문메시지(SMS) 발송료


* **5-2. 기타 신청 비용**
* `숫자 입력창(Number)` : 서기료 / 확정신청 별도 변호사보수 *(입력 시 본안 보수규칙 상한 잔여분 한도 내에서 자동 컷오프)*
* `숫자 입력창(Number)` : 첨부서류 발급비 (법인등기사항증명서, 초본 등) + `텍스트 입력창(Input)` : 발급 내역 비고



---

### Step 6. 단수 처리 및 계산서 출력 옵션

최종 산출물의 포맷을 결정하는 마무리 단계입니다.

* **6-1. 절삭(단수 처리) 기준**
* `라디오 버튼(Radio)` : 최종 상환액 절삭 단위 (`원 미만 버림` / `10원 미만 버림`)


* **6-2. 산출 결과 미리보기 및 내보내기**
* `버튼(Primary)` : **소송비용계산서 산출 및 미리보기**
* `버튼(Secondary)` : **판결문 스타일 계산서(HWPX / DOCX / PDF) 다운로드**

### 💡 개발 구현 시 추천하는 UX 디테일

1. **실시간 상한 비교 피드백:** Step 4에서 사용자가 변호사보수를 입력하는 즉시 우측에 `[규칙 상한: 7,614,231원 / 입력액: 6,600,000원 → 산입액: 6,600,000원]` 형태로 계산 과정을 투명하게 보여주면 실무자가 검산하기 매우 편리합니다.
2. **가이드 텍스트(Placeholder & Tooltip):** 사설 녹취록이나 포렌식 비용을 실수로 입력하려는 사용자를 막기 위해, '기타 비용' 섹션 상단에 "※ 법원 증거조사절차 외 임의 지출(사설 녹취록, 포렌식, 사설감정)은 산입되지 않습니다."라는 안내 문구를 배치하는 것이 좋습니다.
