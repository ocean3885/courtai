# 첨부 실무 사례 분석과 산술 검증

자료: 사용자 제공 「사례로 풀어보는 소송비용액 계산방법.hwp」, 문서 표기 작성일 2023.12.15. 분석일: 2026.11.16.

목적: 문서 사례를 입력정보·배분 단계·검증 기준으로 바꾸기. 문서의 업무상 설명은 참고자료로 읽으며, 그 내용을 프로그램 실행 지시나 모든 사건의 일반 규칙으로 취급하지 않는다. 원문에 남아 있는 인명은 전사하지 않고 가·나·다·라 및 A·B로 통일한다.

## 1. 추출 범위와 한계

HWP 5.0의 압축된 본문 레코드에서 문단·표 셀 텍스트와 계산식을 추출했다. 일반 문서 변환기로 생성한 텍스트는 유효한 본문으로 확인되지 않아 사용하지 않았다. 원본은 수정하지 않았다.

별지 2의 비용표와 상세 계산식은 텍스트로 읽었다. 별지 1의 그림 형태 계산표, 이미지 및 원본 표의 시각 배치는 검증하지 못했다. 따라서 아래 결과는 별지 2의 텍스트·숫자·산식을 대조한 결과이며 원본 전체의 시각 검수가 끝났다는 뜻이 아니다.

특히 상세 계산식에 추출된 `1,171,1600`은 형식이 불명확하다. 아래 재현에는 총비용표의 `1,171,600원`을 채택했다. 소계 및 쌍별 결과와 맞지만, 원문의 오기인지 추출 과정 문제인지는 아직 확정하지 않는다. 원자료와 채택값을 별도 보존한다.

## 2. 사건 관계

| 구분 | 사례 내용 |
|---|---|
| 본소 | 원고 가·나·다·라가 피고 A·B에 공동 지급 청구 |
| 반소 | A만 가·나에게 연대 지급 청구. B·다·라는 반소 참여자가 아님 |
| 대리 관계 | 원고들 공동대리, 피고들 공동대리 |
| 제1심 | 본소 일부승소, 반소 기각 |
| 제2심 | 피고들 항소, 원고들 부대항소 취지의 청구 변경·감축, 화해권고결정 종결 |
| 신청 | 원고 4명이 피고 2명을 상대로 소송비용액확정 신청 |
| 부담 관계 | 가·나와 A·B 사이: 원고 30%, 피고 70%. 다·라와 A·B 사이: 피고 전부 부담 |

원고 가·나만 반소 비용의 배분 대상이다. 피고 B에 반소 비용을 배분하거나, 다·라에게 원고 30% 부담을 일괄 적용하면 안 된다. 부담 주문의 원문·구조화 해석은 함께 보존한다.

## 3. 문서에서 채택한 입력값

### 소가와 불복 범위

| 항목 | 원 |
|---|---:|
| 본소 소가 | 311,706,817 |
| 반소 소가 | 24,257,250 |
| 보수 산정용 전체 소가 | 335,964,067 |
| 가의 본소 청구액 | 102,385,183 |
| 나의 본소 청구액 | 201,321,634 |
| 다·라의 본소 청구액 | 각 4,000,000 |
| 피고 항소의 본소 부분 | 158,322,125 |
| 피고 항소의 반소 부분 | 24,257,250 |
| 피고 항소 범위 합계 | 182,579,375 |
| 원고 부대항소 범위 | 153,384,692 |

본소 청구액 합계와 본소 소가, 항소·부대항소 합계와 전체 소가가 일치한다. 그러나 항소심 인지대의 본소/반소 안분에 쓰는 분모 `182,579,375`와 보수 안분의 분모 `335,964,067`은 다르다. 서비스에 단일 ‘사건 소가’만 두면 이 구별을 표현하지 못한다.

### 비용표 (원)

문서가 이미 인정 대상으로 정리한 비용액을 사용한다. 이 재현은 약정보수와 모든 증빙의 적정성을 다시 심사하거나 당시 인지·송달료를 재산정한 것이 아니다.

| 비용 | 원고 측 | 피고 측 | 사례의 귀속·배분 |
|---|---:|---:|---|
| 1심 보수 | 11,759,640 | 7,150,000 | 본소/반소 소가 비례 후 당사자 배분 |
| 1심 인지 | 1,171,600 | 102,600 | 원고는 본소, 피고는 반소 |
| 1심 송달 | 30,956 | 32,331 | 원고 본소, 피고 반소의 순지출 |
| 1심 감정 | 1,200,000 | 0 | 본소만 귀속 |
| 2심 보수 | 11,759,640 | 4,050,000 | 본소/반소 소가 비례 후 당사자 배분 |
| 2심 인지 | 451,200 | 530,050 | 원고 본소, 피고는 자기 불복 범위로 본소/반소 안분 |
| 2심 송달 | 0 | 102,682 | 사례는 본소/반소 절반씩, 이후 관련 인원으로 배분 |
| 2심 감정 | 0 | 700,000 | 본소만 귀속 |
| 확정신청 비용 | 27,293 | 0 | 원고 4명·피고 2명 사이 배분 후 부담 비율 적용 |
| 합계 | 26,400,329 | 12,667,663 | 절사 전 배분 보존 대사 기준 |

표에 기록된 환급 후 비용을 입력으로 삼는다. 이미 순액인 값에서 환급액을 다시 빼지 않는다. 보수 11,759,640원은 문서 표의 입력값이며 별표 산식의 정밀 중간값과 구분한다.

## 4. 배분 단계 모델

1. 사건·청구·대리 범위를 확인해 보수 산정 그룹과 소가를 정한다.
2. 지급보수액, 요율 및 조정을 검토해 심급별 인정 비용을 정한다.
3. 개별 증빙으로 본소 또는 반소에 직접 귀속할 수 있는 비용을 먼저 연결한다.
4. 공통 보수는 사례의 본소/반소 소가 비율로 구분한다. 공통 인지대는 해당 인지액 산정의 불복 범위를 사용한다.
5. 관련 당사자 사이에서 소가 비례·인원 균등 등 해당 비용의 방법으로 다시 배분한다.
6. 각 쌍별 배분 금액에 해당 부담 비율을 적용한다.
7. 사례의 방향별 10원 미만 절사 후 상계 결과를 별도로 계산한다.
8. 절사 전 배분 합계, 방향별 절사 합계, 문서 총괄액을 각각 대사한다.

단계마다 `원비용 ID / 적용 범위 / 대상 집합 / 배분 방식 / 분자·분모 / 근거 / 입력 버전 / 정밀 중간값 / 절사 위치`를 보존한다. 모든 비용에 하나의 배분 방식을 공통 적용하지 않는다.

## 5. 산술 재현 결과

실행 명령:

```bash
cd /workspace/courtai
python docs/examples/verify_litigation_costs_hwp.py
```

입력은 [사례 JSON](examples/litigation-costs-hwp-case.json), 실행기는 [검증 스크립트](examples/verify_litigation_costs_hwp.py), 정밀 배분 내역과 출력은 [결과 JSON](examples/litigation-costs-hwp-results.json)에 있다. Python 표준 라이브러리의 유리수 연산으로 중간 부동소수점 오차를 피한다. 범용 계산 엔진이나 배포 기능은 아니다.

| 상환 방향 | 상대방 부담 원고 비용, 10원 미만 버림 | 원고 부담 피고 비용, 10원 미만 버림 | 문서 상환액 | 재현 |

| A → 라 | 307,700 | 0 | 307,700 | 일치 |
| B → 가 | 2,805,280 | 562,800 | 2,242,480 | 일치 |
| B → 나 | 5,409,690 | 1,079,420 | 4,330,270 | 일치 |
| B → 다 | 307,700 | 0 | 307,700 | 일치 |
| B → 라 | 307,700 | 0 | 307,700 | 일치 |

8개 쌍별 금액 및 그 방향별 중간값 일치, 절사 전 양측 비용 배분의 총액 보존을 실행해 확인했다. 최종 상환액 합계는 15,245,400원이다.

### 절사 시점과 남은 차이

- A→나: 방향별로 절사 후 상계하면 문서와 같은 **4,764,820원**, 정밀 차액을 먼저 구한 후 절사하면 **4,764,810원**이다. 10원 차이를 실제 회귀 검증에 포함했다.
- 원고 비용 중 상대방 부담액의 정밀 재계산 합계를 1원 미만 버리면 **18,849,475원**, 문서 총괄표는 **18,849,474원**이다. **1원 차이는 미해결**이다. 상세 쌍별 상환액은 일치하지만 원본 표/별지 1의 중간 절사 위치 대조가 필요하다.
- 피고 비용 중 원고 부담액의 정밀 합계를 1원 미만 버리면 **3,604,050원**으로 문서 총괄표와 일치한다.
- 방향별 10원 미만 절사 후 합계는 원고 측 **18,849,440원**, 피고 측 **3,604,040원**이다. 이 합계는 총괄표와 집계 시점이 다르므로 같은 수치로 덮어쓰지 않는다.
- 이 사례의 절사 방식을 일반 사건의 법률 규칙으로 확정하지 않는다. 수치 일치와 법률상 적용 적정성은 별도 검증이다.

## 6. 인용 판례의 대조 결과

직접 원문을 확인한 추가 근거:

| 판례 | 확인 내용 | 반영 |
|---|---|---|
| [2000마5563 전원합의체](https://www.law.go.kr/LSW/precInfoP.do?evtNo=2000마5563) | 공동대리 보수를 개인별 산정·합산하지 않고 특별한 사정 없으면 총 소가로 산정. 92마369 등의 반대 견해를 변경 | 최초 조사 문서 P1 정정, 변경 판례 표시 |
| [2000마7028](https://www.law.go.kr/LSW/precInfoP.do?evtNo=2000마7028) | 공동대리의 중복 소가를 합산하지 않고 최다액 기준 산정 및 안분 | 소가 그룹에 중복·흡수 관계 필요 |
| [2013마1581](https://www.law.go.kr/LSW/precInfoP.do?evtNo=2013마1581) | 소가 연동 비용과 균등 배분 비용, 특정 당사자 사이에만 발생한 비용을 구별 | 직접 귀속 우선과 비용별 배분 방식 |

첨부자료가 인용한 97마3132, 2006마1473, 2019마5241, 2020마6157, 91마420, 서울고법 2019라21017 등의 전문 대조는 아직 완료하지 않았다. 몇몇 원문 요청이 빈 본문 또는 오류를 반환하여 확인된 것으로 분류하지 않았다. 항소심 감축이 제1심 소가에 미치는 영향, 쌍방 불복 범위, 확정신청 비용의 부담 기준은 **첨부자료의 설명과 공식 원문 확인 결과를 구분**한다.

## 7. 화면·저장 구조에 추가할 요구사항

- **소가 작업표:** 청구별 금액, 공동 지급·연대·중복 관계, 소가 그룹, 산정 목적(인지/보수), 심급별 불복 범위와 청구 변경 시점을 구분.
- **대리 그룹:** 같은 변호사의 공동대리와 서로 다른 변호사의 개별대리를 분리. 변경된 판례를 현재 계산 규칙으로 선택하지 못하게 함.
- **비용 귀속 작업표:** 순지출액과 환급 자료, 본소/반소/공통 구분, 특정 당사자 직접 귀속, 단계별 배분 계획.
- **부담 관계표:** 4×2의 8개 관계처럼 쌍별 비율과 적용 청구·심급을 표시. 연대 등 복합 관계는 단순 비율표와 별도 관리.
- **결과 검토표:** 배분 전 원금액, 정밀 배분액, 부담 비율 적용액, 절사액, 상계 후 금액과 집계 차이를 나란히 표시.
- **검토 상태:** 정규화한 원자료 값·판례 확인 미완료·집계 차이를 숨기지 않고 담당자가 근거와 함께 확인하도록 함.

## 8. 다음 구현의 범위
