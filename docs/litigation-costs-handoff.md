## 1대1 본소 간편 배분 — 2026-11-17

사용자가 입력폼 검토의 다음 우선순위 작업을 요청했다. [간편 배분 문서](litigation-costs-simple-allocation.md)에 따라 기존 비용 귀속자·청구를 가져와 부담 관계를 확인하면 전액 귀속 계획과 배분 대상을 함께 설정한다. 신규 계획은 직접 말단으로 만들고 기존 단일 경로의 균등 단계는 보존한다. 다수 당사자·반소·가중치·공동 귀속·환송은 직접 편집한다. 신청비용의 타 절차 주문 준용은 근거를 요구하고, 여러 후보는 명시적으로 선택한다. 임시 선택은 적용해야 초안에 반영되며 사례 교체·복원 시 초기화한다. 저장 형식과 계산식은 유지한다.

자동 테스트 107건과 신규 생성·기존 경로 수정·저장 복원·모바일·PDF 검증을 추가했다. 신규 F01 계획의 차액 4,407,000원과 1/2 부담 주문 적용 후 2,207,000원을 실제 화면에서 확인했다. 다음에는 필수·선택·해당 시 입력 표시와 사건번호·소가 자료 가져오기 등 중복 입력을 줄이는 작업을 권한다.

## 심급별 소가·실비의 보수 자동 산입 — 2026-11-17

사용자가 심급별 소가와 변호사보수 실비를 입력하면 자동 산입액과 산식을 결과물에 반영하라고 요청했다. [구현·검증 문서](litigation-costs-attorney-fees.md)에 따라 2020.12.28. 별표 8개 구간, 실비·환급 비교, 명시적인 제5조 1/2 유형을 구현했다. 한 계산 결과를 화면 합계·배분·상계·PDF 비고와 심급별 소계에 사용한다. 자동 입력은 비용의 선택 필드로 v2 초안에 보존하고, 과거 수동 입력과 기존 사례는 유지한다.

출력 검증 목록에 F01(실비 1천만원/한도 440만원), F02(실비 330만원), F03(3개 심급별 입력)을 추가했다. 자동 테스트 97개, 린트·빌드와 새 3개·기존 7개 PDF, 입력 폼 회귀 검증을 통과했다. 독립 Python 한계 구간 계산의 34개 정밀 입력과 실제 PDF 산식을 검증한다. 같은 심급·중복 귀속 당사자의 보수를 여러 행에서 각각 자동 상한 계산하는 구성은 보류한다. 과거 별표·제6조 조정·환송·신청 대리 보수는 수동 검토 대상이다. 자동 보수 입력값은 수동 산정 그룹·배분 가중치와 구분한다.


## 입력폼을 한 페이지 목차로 변경 — 2026-11-17

사용자는 탭에 분산된 입력보다 한 페이지에서 주요 목차별 접기·펼치기와 전체 보기가 가능한 형태를 요청했다. 기존 5개 입력 단계를 한 페이지의 목차로 옮기고 계산서 출력을 6번째 목차로 분리했다. 목차 링크는 해당 항목을 열어 이동하며, 전체 펼치기는 내부 비용·배분·근거의 세부 항목도 연다. 첫 진입에는 사건·당사자를 열고 나머지는 접는다. 입력 내용·생성한 미리보기는 접었다고 초기화하지 않는다.

브라우저 초안·계산 모델은 유지했다. 오류 이동, 사례 불러오기, 저장·복원과 PDF 검증 도구를 목차 구조에 맞췄다. 키보드, 390px 모바일, 1280/1440px 화면의 고정 목차 위치, 84개 관계, 미리보기 유지와 입력 변경 후 무효화를 브라우저에서 확인했다. 전환 후 자동 테스트 75개, 린트·빌드와 기존 7개 PDF 출력 검증도 통과했다. 검증 명령은 `node docs/examples/check_litigation_costs_form.mjs`이며, 자세한 현황은 [입력 화면 문서](litigation-costs-prototype.md)에 있다.


## 단순 사례부터 출력 검증 — 2026-11-17

사용자는 단순한 비용분담 사건부터 사례를 여러 개 만들고 결과물을 하나씩 검증·수정하며 복잡한 유형으로 확장하자는 개발 방식을 명시했다. [출력 검증 문서](litigation-costs-output-validation.md)에 첫 7개 입력·독립 기대 값·금액/문서/지면 검증 순서를 기록했다. 원고/피고 전부승소, 일부승소·상계, 역방향 차액, 각자 부담, 절사 시점, 3개 심급을 포함한다.

원고 1명·피고 1명의 본소에 대해 기존 계산 결과를 독립 HTML 계산서로 구성하고, 배분·검토 화면에서 미리보기·인쇄/PDF 저장을 제공한다. 미지원 다수 당사자·반소·환송은 출력 보류한다. 입력을 수정하면 이전 생성본을 숨기고 인쇄를 막으며 다시 생성해야 한다. 생성본은 화면 상태에만 보관하고 사건별 서버 저장·확정 기능은 아직 제공하지 않는다. 다음에는 이번 계산서의 사용성·금액·지면 피드백을 보완하고 다수 당사자·S06 범위 처리로 확장한다. 자동 테스트 75개, 독립 분수 검산 및 실제 화면에서 생성한 7개 1쪽 A4 PDF의 금액·방향을 확인했다. 긴 비고를 넣은 다쪽 표와 모바일·입력 변경 후 재생성도 검증했다. 산출물은 `/workspace/courtai-research/report-validation-2026-11-17`에 있다.


## 최종 산출물 목표 확인 — 2026-11-17

사용자는 **사건별로 첨부 PDF와 같은 형태의 소송비용계산서가 출력되는 것**을 최종 결과물로 명시했다. 입력·계산·검토 결과를 사건 표시, 심급별 비용표, 신청비용, 당사자별 상환액, 산식·각주·별지로 자동 구성해 미리보기·인쇄·PDF 저장을 제공하는 방향이다. [출력 설계](litigation-costs-output-spec.md)에 범위·출력 데이터·지면·구현 순서를 정리했다. 그 뒤 1:1 본소의 검토용 출력과 아래 7개 사례 검증을 1차 연결했다. 다수 당사자·반소·환송 출력은 후속 범위다.

## 참고 PDF 접수 — 2026-11-17

사용자 첨부 PDF 계산서 9개(총 16쪽)를 [프로젝트 참고자료 보관함](../references/litigation-costs/README.md)에 저장했다. 전 페이지 텍스트 참고 검토, PDF-04·05·08 일부 표의 시각 대조, 일부 산술 검산을 진행했다. 원본·추출문·원본명 대응표는 실제 당사자명·사건 식별정보가 있어 Git 제외다. 파일별 SHA-256·페이지 수와 익명화된 주제·미해결 차이는 [접수 목록과 메모](../references/litigation-costs/2026-11-17/README.md)에 남겼다. ## 유형별 사례 확장 — 2026-11-16

기본 12개·특수 6개를 ‘유형별 사례’에서 불러와 현재 계산기에 연결했다. 원문 사례 13개는 8개 일치·5개 차이, 구조 재구성 5개는 3개 가계산·2개 미지원 보류다. 독립 Python 분수 검산과 18개 사례를 포함한 자동 테스트 60개가 통과했다. 자세한 출처·미해결 차액은 [유형별 사례 검증](litigation-costs-case-library.md)을 참조한다.

사례 ID는 v2 초안의 선택 필드로 저장한다. 수정 시 원문 비교표를 숨긴다. 다음 권장 구현은 전체 본안 귀속을 유지하면서 공동소송인 일부의 신청 관계만 선택하는 범위 처리(S06)다. 연대 부담(S05)은 별도 의무 구조가 필요하다. 당시 후속 범위였던 보수 자동 산입은 위의 2020년 별표 기본형을 구현했다. 사임/재선임·본안 상계항변과 다른 별표·특수 조정은 후속 범위다.

## 이전 추천 작업 — 아래 구조화·계산 연결은 완료

1. 현재 메모로 입력하는 당사자·심급·청구별 가액과 불복 범위를 구조화한다.
2. 공동대리 보수 산정 그룹, 비용별 배분 단계·대상·가중치, 절사 단위·시점을 별도 데이터로 만든다.
3. 직원이 검토한 인정액을 출발점으로, 8개 상환액이 재현된 사례의 배분 계산을 먼저 연결한다.

- `python docs/examples/verify_litigation_costs_hwp.py`: 기존 첨부자료의 8개 쌍별 상환액 재현. 절사 전 비용 배분 총액 보존 확인.
- `python docs/examples/verify_manual_arithmetic.py`: 대표 산술 점검 및 미해결 불일치 기록.

## 반드시 유지할 미해결 사항

- 첫 첨부자료: 총괄표의 정밀 합계와 1원 차이. 방향별 10원 미만 절사 후 상계와 상계 후 절사는 결과가 다를 수 있음.
- 두 번째 첨부자료: 반소 사례의 인지대 327,400원 누락 의심. 비교 경로의 최종액 차이 81,850원. 원본 시각 대조 전 정답 수정으로 확정하지 않음.
- 구요율·지역 실무례·저자 견해를 현행 자동 규칙으로 그대로 사용하지 않음.
- 92마369의 공동대리 보수 개별 산정 견해는 2000마5563 전원합의체로 변경되었음. 변경된 구 판례를 운영 규칙으로 선택하지 않음.
- 본안 상계항변, 비용 법정상계, 절차 밖 변제·상계·면제, 신청권·청구권 포기는 구분. 지급 사실만으로 확정액을 차감하지 않음.
- 원본 HWP·추출본·브라우저 스크린샷은 Git 커밋에 포함하지 않음. 다음 환경에 필요하면 기존 첨부 파일을 사용한다. 환경의 파일·실행 프로세스 복원은 Git 푸시와 별개다.
