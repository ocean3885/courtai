# 유형별 비용분담 사례와 계산 검증

소송비용액확정 화면의 **유형별 사례**에서 기본 12개와 특수 6개를 선택할 수 있다. 선택한 사례는 기존 입력 형식으로 불러오며, ‘배분·검토’에서 현재 입력의 가계산과 원문 기재액을 따로 표시한다. 사례 교체 전 기존 입력에 대한 교체 확인을 유지하고, 브라우저 저장본은 저장 버튼을 누르기 전까지 보존한다.

## 출처와 범위

- 원문 사례 13개: 사용자 첨부 `사례중심 소송비용액확정실무.hwp`의 기본 12개 유형과 본소·반소 사례 1개. 아래 쪽수는 문서의 인쇄 쪽수다.
- 구조 재구성 5개: 기존 공식 자료 조사와 실무서의 부담 구조를 참고한 개발용 입력이다. 금액은 임의 구성했으며 실무서 원문 계산례로 표시하지 않는다.
- 문서의 **환급 후 인정액**을 출발점으로 삼는다. 과거 보수표를 현행 법정 한도로 적용하지 않는다. 주문 요약과 명시적 분담 비율을 구조화했으며, 주문 문장을 자동 해석하거나 효력을 확정하지 않는다.
- 신청비용의 부담·배분은 해당 사례의 경로만 입력했다. 특히 S01의 신청비용 전액 상대방 부담은 문서가 소개한 실무례이며 범용 규칙이 아니다. S01에서 상대방 미제출 사실을 추정하지 않는다.

## 데이터와 독립 검산

- `src/lib/fixtures/litigation-costs-cases.json`: 자료의 인정액, 비용 귀속 가중치, 관계별 배분 가중치, 방향별 부담 비율, 원문 기재액, 출처·검토 메모.
- `src/lib/litigation-costs-case-library.ts`: 사례를 일반 초안의 가액·산정 그룹·대리 관계·배분 트리로 변환한다. 계산 엔진에 사례 ID별 산식이나 결과를 하드코딩하지 않는다.
- `docs/examples/verify_litigation_costs_cases.py`: TypeScript 변환기와 계산기를 사용하지 않고 원자료의 가중치를 `Fraction`으로 직접 검산한다. `--check`는 저장된 검산 결과의 최신 여부를 확인한다.
- `docs/examples/litigation-costs-case-oracle.json`: 정밀한 양방향 금액, 절사 후 결과, 비용 총액 보존, 원문 차액. 큰 분자·분모는 문자열로 보관한다.
- `tests/litigation-costs-case-library.test.cjs`: 18개 사례의 상태와 모든 정밀 금액을 독립 검산과 비교한다. 심급별 참여 범위, 일부 당사자 공동대리, 주문 선택, 각자 부담, 원문 차이, 초안 저장 호환성도 점검한다.

16개 가계산 사례의 135개 쌍별 결과·373개 배분 말단·67개 비용의 총액 보존을 대조했다. 2개 미지원 사례는 출력 금액·배분 경로를 비우는 것을 검증한다. **자동 테스트 통과는 원문 차액 해소나 법률상 적정성 확정을 뜻하지 않는다.**

## 화면의 비교 조건과 한계

선택한 기준 입력을 수정하면 원문 비교표를 숨기고 현재 입력의 가계산만 갱신한다. 다시 원문과 비교하려면 같은 사례를 재선택한다. 선택한 사례 ID는 v2 초안의 선택 필드 `referenceCaseId`로 저장하며 이전 v1/v2 초안의 복원을 유지한다.

S04는 직원이 계획에 연결한 주문만 사용한다. 상급심 주문이 기존 주문을 대체하는지 자동 판정하지 않는다. S05·S06에 대한 계산 보류는 현재 구현의 한계이며 해당 소송관계의 법률상 계산 불가능을 뜻하지 않는다. 변호사 중도 사임·재선임, 본안 상계항변의 소가 처리, 선행 확정·신청 범위별 한도, 보수 한도 자동 산정은 추가 개발·검증이 필요하다.

다음 구현 우선순위는 **공동소송인 일부 신청의 범위 처리**다. 전체 본안 관계에서 귀속 몫을 유지한 채 신청 대상 관계만 결과로 선택하는 구조를 마련하고 S06을 정상 계산 사례로 전환한다. 연대 부담은 단순 균등 분할로 대체하지 않고 별도 의무 구조와 중복 집행 방지를 설계한다.

- `python docs/examples/verify_litigation_costs_cases.py --check`: 독립 검산 결과와 일치.
- Chromium: 기본/특수 사례 필터, 교체 취소 시 입력·저장본 보존, S01의 81,850원 차액 표시, 비용 수정 후 재계산과 원문 대조 중단, S05·S06의 이전 결과 숨김, S03의 각자 부담 표시, B11의 84개 관계와 사례 ID 저장·복원, 390px 모바일 내부 스크롤과 가로 넘침 없음, 페이지 오류 없음.
