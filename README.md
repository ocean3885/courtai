# Court-Easy (법원이지)

Next.js 기반 개인회생 서류 작성 서비스입니다. PostgreSQL(Supabase 포함)에 사건과 문서를 저장하며, 비회원은 브라우저에서 문서 작성을 체험할 수 있습니다.

## 현재 기능

- 회원가입, 로그인, 비밀번호 변경 및 관리자/일반 사용자 권한
- 채무자·일반채권·우선채권·별제권·대위변제자 입력
- 개인회생 사건 저장·불러오기·검색·삭제
- 채권자목록과 변제계획안 생성, 변경사항 조회, 브라우저 인쇄/PDF 저장
- 생성 시점의 계산 결과와 두 문서 HTML 보존
- 비회원 미리보기(입력값은 해당 브라우저 localStorage에 저장)
- 문의 접수 및 관리자 문의 조회, 사용자 권한 변경·삭제

소송비용 계산, AI 호출, PDF 자동 분석, 문의 답변 전송은 현재 구현되어 있지 않습니다.

## 개발 실행

Node.js 20.9 이상을 사용합니다.

```bash
npm ci
cp .env.example .env.local
# .env.local에 테스트 DB와 비밀값을 설정합니다.
npm run dev
```

먼저 `supabase/migrations/202607180001_create_courtai_schema.sql`을 테스트 DB에 적용해야 합니다. 상세 설정은 [DEPLOYMENT.md](DEPLOYMENT.md)를 참고하세요.

```bash
npm test
npm run lint
npm run build
```

## 인증과 문서 이력

- 로그인 토큰은 HttpOnly 쿠키로 전달되며 최대 하루 동안 유효합니다.
- 매 요청마다 현재 계정 상태와 권한을 조회합니다. 계정 삭제·비활성화·권한 변경은 다음 요청부터 반영됩니다.
- 비밀번호를 변경하면 모든 기존 로그인 토큰이 무효화되고 다시 로그인해야 합니다.
- 초기 관리자 환경변수는 **최초 계정 생성 시에만** 사용합니다. 재배포로 비밀번호를 덮어쓰지 않습니다.
- 이번 인증 변경 이전에 발급된 토큰도 무효화되므로 배포 후 사용자는 다시 로그인해야 합니다.
- 새 문서는 생성 당시 HTML을 저장하므로 계산식 변경 후에도 같은 내용을 보여줍니다. 기존 형식의 문서는 저장된 입력값으로 다시 계산하며 화면에 해당 사실을 표시합니다.
- 사건 삭제 시 해당 사건의 문서도 삭제됩니다. 연결 데이터가 남아 있는 사용자는 데이터 보호를 위해 삭제를 거부합니다.

## 계산 기준

일반채권은 원금, 별제권부 채권은 변제받을 수 없는 채권액을 대상으로 계산합니다. 우선채권을 먼저 배당하고 잔여 재원을 일반채권에 원채권액 비율로 배당합니다. 모든 지급액은 잔액을 한도로 하며 원 단위 오차를 보정합니다. 압류적립금은 기존 서비스의 규칙에 따라 총 가용소득에 포함된 재원으로 처리합니다. 변제기간은 1~120개월을 지원하며, 실제 사건에 적용할 법률·법원 기준은 별도로 확인해야 합니다.

## 운영 시 제한

로그인은 계정별로 프로세스당 15분간 10회로 제한합니다. 여러 인스턴스를 쓰거나 서버리스로 배포할 때는 게이트웨이 또는 공유 저장소를 통한 추가 제한이 필요합니다. 테스트는 계산·HTML·인증·트랜잭션 동작을 검증하며, 운영 Supabase와 배포 환경의 통합 검증은 별도로 수행해야 합니다.
